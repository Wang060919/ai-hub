/knowledge/* 手动操作入口。页面加载时可能自动刷新状态， 但不会自动索引、搜索或问答。

知识库状态

仅调用 GET /knowledge/status 刷新状态。

等待知识库状态刷新。

Markdown / Obsidian 笔记手动入库（单篇）

仅在手动点击按钮后调用现有 POST /knowledge/index-file。

当前入口只复用现有单文件入库能力，不新增 Markdown / Obsidian 专用后端。

  • 路径必须位于当前白名单目录内。
  • 第一版只支持单篇 Markdown 笔记手动入库。
  • 不会自动扫描 Vault。
  • 不会自动读取整个 Obsidian 库。

输入单篇 Markdown 相对路径后手动接入；不会自动扫描、不会自动入库。

Markdown 目录手动批量入库

仅在手动点击按钮后调用 POST /knowledge/index-markdown-directory。

当前只支持白名单根目录内的相对目录，且仍保持手动触发边界。

  • 目录必须位于当前受控白名单根目录内。
  • 只处理 .md 文件。
  • 自动忽略 .obsidian、隐藏项、attachments、assets、images。
  • 不会自动扫描全盘，不会自动入库。

输入相对目录后手动批量接入；不会自动扫描、不会自动入库。

知识库搜索

搜索使用 POST /knowledge/search，不调用模型。

输入查询并点击搜索知识库。此操作不会调用模型。

知识库问答

仅点击按钮后调用 POST /knowledge/query。

输入问题并点击知识库问答。仅在点击时调用模型。
