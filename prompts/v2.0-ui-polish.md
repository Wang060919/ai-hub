## 本轮目标

请对当前前端 UI 做一次只读审查，判断页面现在有哪些体验问题、视觉不统一问题、信息层级问题，以及 V2.0 应该如何改。

重点不是增加新功能，而是把现有功能变得更像一个成熟桌面产品。

## 请重点审查

### 1. 整体 UI 一致性

检查当前页面是否存在：

- 卡片样式不统一
- 按钮层级不统一
- 输入框样式不统一
- 状态提示样式不统一
- 错误提示样式不统一
- 空状态不统一
- 中英文或术语不统一
- 间距、圆角、阴影、边框风格不统一
- 信息密度过高或过低

### 2. Panel 主入口体验

检查 Panel 是否适合作为桌面启动后的第一屏。

重点看：

- 后端状态摘要是否清楚
- 知识库 / Markdown 摘要是否清楚
- 快速 Chat 是否好用
- 入口按钮是否清楚
- 是否像“项目管家面板”
- 是否只是功能堆叠
- 哪些信息应该保留
- 哪些信息应该隐藏或弱化
- 是否需要更明显的主操作区

### 3. Chat 页面体验

检查 Chat 页面当前体验，尤其是 V1.9 新增的普通聊天 / 知识库问答模式。

重点看：

- 普通聊天和知识库问答的模式切换是否清楚
- kb_id / top_k 参数是否应该默认展开
- 知识库问答结果展示是否清楚
- citations / hits 展示是否太复杂
- KNOWLEDGE_MODEL_DISABLED 等错误是否对普通用户友好
- Chat 消息区视觉是否统一
- user / assistant / knowledge assistant 的身份标识是否清楚
- 是否需要更好的空状态和提示文案

### 4. Knowledge 页面体验

Knowledge 页面现在功能很多：

- 知识库状态
- 单篇 Markdown 入库
- Markdown 目录批量入库
- 搜索
- 问答

请检查：

- 当前排版是否过长
- 区块顺序是否合理
- 单篇入库和目录入库是否应该合并或分组
- 搜索和问答是否应该更清楚地区分
- 状态、入库、搜索、问答是否需要二级导航或折叠
- 结果展示是否统一
- 错误和边界提示是否太多或太挤

### 5. Files / Tools 页面体验

检查：

- 文件预览和文件总结是否清楚
- 工具卡片是否和其他卡片风格一致
- 文件路径输入是否直观
- 总结按钮状态是否清楚
- 空状态和错误状态是否自然

### 6. 移动端 / 小窗口适配

虽然当前不是手机端，但 Tauri 窗口已经调小。

请检查：

- 1120x820 下页面是否适合
- 更窄窗口下 Panel 是否还能看
- Tab 是否拥挤
- 卡片是否需要响应式优化
- 是否需要降低信息密度
